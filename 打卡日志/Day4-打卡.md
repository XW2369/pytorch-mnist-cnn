# Day4-打卡.md
【今日技术收获】3条
1. 手动推导反向传播梯度，并用`float64`双精度校验手写backward和torch autograd，验证梯度实现正确性，理解浮点机器精度。
2. 搭建SmallCNN与ResCNN，在MNIST上对比，认识残差结构可以提升精度，但要警惕参数量这类混杂变量，不能直接归因给残差。

【代码产出】

【交付物】
训练报告md、loss曲线图、Day4指标汇总表，代码与测试用例，git提交记录。

【卡住的地方 + 怎么解决】
1. venv未激活，裸python找不到torch，反复踩坑3次。解决：固定工作流，新开终端第一件事激活虚拟环境，写脚本前加环境检查。
2. 模块顶层裸写计算代码`z1 = X @ W1 + b1`，导入模块直接触发NameError。解决：把执行代码放进`if __name__ == "__main__":`保护块。
3. pytest没正确接入模型模块，但仍然4 passed，出现测试假象。解决：重新梳理测试依赖，校验测试输入输出，确认测试真的调用目标代码。
4. 一开始没创建.gitignore，MNIST数据集被纳入版本库，23MiB大文件提交进git历史。解决：新建.gitignore屏蔽数据集目录；后续新项目优先建立gitignore。

【砍掉清单】
原定尝试3种不同残差变体；砍掉，优先保证基础模型、梯度校验、指标对比交付。

【自评】

【今日八股】
残差网络为什么能缓解梯度消失：引入恒等短路连接，梯度可以直接沿shortcut回传，避免连续矩阵乘法造成梯度不断衰减，使得深层网络可收敛。
